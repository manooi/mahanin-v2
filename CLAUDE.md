```bash

```

There are no test or lint commands — this is a static site.

## Architecture

Personal site at [mahanin.com](https://mahanin.com), built with Astro (static output). Two pages:

- `src/pages/index.astro` — the hub: links to resume, Unsplash photography, GitHub projects
- `src/pages/resume/index.astro` — the resume, printable to PDF via the "Save as PDF" button
- `src/layouts/Base.astro` — shared head/meta shell; pages pass title/description/canonical/og props

**Key design decisions:**
- Performance budget: each built page stays around 20KB of HTML+CSS; no client-side JS frameworks. The only JS is a small inline script on the resume page (age counter, IT-years counter, print-title swap) kept as `<script is:inline>` so Astro never bundles or defers it.
- All CSS is inlined into the HTML (`build.inlineStylesheets: 'always'` in `astro.config.mjs`) — no render-blocking stylesheet requests.
- Tailwind v3 via `@astrojs/tailwind`; utilities are purged against `src/**/*.astro`. Custom non-Tailwind CSS (`.resume-box`, `@media print` PDF styles) lives in `<style is:global>` blocks inside the page that owns it.
- The resume's `@media print` block powers PDF export (page margins, 12px root font scaling, `.no-print`, page-break rules). Do not scope or restructure it.
- Static files (images as WebP, favicon, robots.txt) live in `public/`; `assets/profile.jpg` is kept as JPG because it serves `og:image` for link-preview scrapers.
- Sitemap is generated by `@astrojs/sitemap` (`sitemap-index.xml`, referenced from `public/robots.txt`).
